PASOS PARA SUBIR A GITHUB DESKTOP

1. Descomprime este ZIP.
2. Abre GitHub Desktop.
3. File > Add Local Repository.
4. Selecciona la carpeta descomprimida.
5. Publica el repositorio.
6. En GitHub web entra a Settings > Pages.
7. En Branch selecciona main y /root.
8. Guarda.
9. Abre el link de GitHub Pages.

IMPORTANTE PARA QUE FUNCIONE ENTRE COMPUTADORAS

GitHub Desktop solo sube la app.
Supabase es la base de datos. Debes ejecutar el archivo:

supabase_schema.sql

Dónde:
Supabase > SQL Editor > New query > pegar todo > Run

Luego abre la app publicada y presiona:
"Probar conexión Supabase"

FLUJO DE PRUEBA
1. Computadora 1 abre el link de GitHub Pages y entra en Helados.
2. Genera un pedido.
3. Computadora 2 abre el mismo link, entra en Caja, inicia sesión.
4. Presiona Actualizar pedidos o Probar conexión.
5. Debe aparecer el pedido.
