Cero Grados v80 - Pedidos + Caja

1. Ejecuta supabase_schema.sql en Supabase.
2. Sube index.html y .nojekyll al repositorio.
3. Abre GitHub Pages con ?v=80.
4. Tablet 1: Pedidos.
5. Dispositivo 2: Caja.
6. Caja se actualiza cada 3 segundos.

La app usa:
- Project URL de Supabase
- sb_publishable_... (publishable key)
- REST API directa
No usa service_role ni secret keys.
