Cero Grados v40 Supabase - Sin Caja digital

Flujo:
1. Cero Grados captura pedido.
2. Imprime ticket.
3. Cliente paga en Caja física con el ticket.
4. Cliente regresa a Cero Grados.
5. Cero Grados marca Entregado o No entregado.
6. Historial queda en Supabase y se comparte entre computadoras.

Importante:
- No incluye módulo de Caja digital.
- Si Supabase falla, usa modo local de respaldo para no detener operación.
- Para compartir historial entre computadoras, Supabase debe conectar correctamente.

Pasos:
1. Ejecuta supabase_schema.sql en Supabase.
2. Sube esta carpeta descomprimida a GitHub Desktop.
3. Abre la página con ?v=40.
